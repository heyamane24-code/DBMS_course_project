PROFESSIONAL TRAINING INSTITUTE MANAGEMENT SYSTEM UI

1. Open app.py in VS Code.
2. Update DB_CONFIG with your MySQL password and database/schema name.
3. Open Command Prompt in this folder.
4. Install connector if needed:
   py -m pip install mysql-connector-python
5. Run:
   py app.py

Features:
- Professional dashboard
- View all 11 project tables
- Search records
- Insert records
- Delete records with confirmation
- Database information page
- MySQL-backed live CRUD operations

IMPORTANT:
This program assumes your database tables are already created with the same names and columns used in your project.
